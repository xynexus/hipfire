# R61 — complete resident-bundle QKV projection

R61 expands R60's first scaled 4x16 tile across all four R34 row stripes, six
W4 output blocks, eight columns, and three K=256 groups. It consumes the exact
existing 2,949,120-byte shared activation argument and the complete R34
QKV/O/parameter bundle. The AIE kernel performs only the local R34 8+8-to-16
activation join and signed-W4 MMUL handling; global weight blocks remain in
`.rdna2.hfp` order.

The graph drains the established whole-scaled physical output contract:
`[column][outblock][row-stripe][2304 f32]`. The verifier deblocks all
M256/N1280 values and compares them against a canonical CPU projection while
also checking the padded M288/N1536 extent.

## Hardware result

Three locked trials of the admitted raw graph pass all 327,680 real outputs and
the complete padded M288/N1536 image with `max_abs=3.8147e-6`. The final
tile-local 6-KiB vector-view variant has a 4.114-ms median NPU time
(3.900-4.476 ms), 0.122 useful TOPS at the median. This is a correctness and
placement result, not a performance admission: it is about 4.9x slower than
R58's 0.8635-ms whole-scaled wrapper control.

The progression isolates the cost:

- scalar 8+8 activation assembly: 6.870-ms median;
- native 32-byte loads plus `interleave_zip(..., 8)`: 4.238 ms;
- materializing one reusable 6-KiB W4 view in tile SRAM: 4.114 ms.

The last step does not improve the median, so adding more tile-local caching is
not the next lever. R62 tests a producer-native W4 activation view while
keeping immutable weight blocks in `.rdna2.hfp` order. Its later result shows
that this was a useful control but not the dominant explanation; see R62/R63
before using the R61 timing to select an ABI.

Failed topology attempts are retained in `r61_run.py`: 32 independent output
drains exhausted shim DMA capacity; joining outputs then exposed the high-level
object-FIFO transform's lock-allocation limit. The raw R16 topology fixed both.

The first high-level IRON versions are retained as `r61_run.py`; they document
shim-DMA and object-FIFO-lock placement failures. The admitted graph is the
raw-MLIR R16 topology generated by `r61_gen.py`.

Build and run under `hipfire lock`:

```bash
export PYTHONPATH="/opt/xilinx/xrt/python"
export LD_LIBRARY_PATH="/opt/xilinx/xrt/lib:/opt/rocm/lib"
export MLIR_AIE_INC="$HOME/.venv/lib/python3.14/site-packages/mlir_aie/include"
export R61_R34_BUNDLE_HFP="$HOME/.hipfire/npu/prepacked/EmbeddingGemma-300M.npu.oq4.layer-0.r34-bundled-bo.rdna2.hfp"
./build_r61.sh
python run_matrix.py
```
