## Why this happened (analysis)

The same root failure as the three prior session levers:

1. **Proxy mismatch**: BRECQ-style per-Linear MSE measures `||W_qx -
   Wx||² ` per Linear independently. The optimizer found a configuration
   that reduces this proxy by ~8% in aggregate but does NOT correspond
   to a configuration that reduces model logit divergence.

2. **Joint-optimization cancellation**: The smoke gate (6 layer-0
   tensors only) showed butterfly residual gives −2.5% KLD. The full
   138-tensor training reversed sign to +0.3% KLD. Cross-tensor gradient
   interactions in joint SGD created conflicting updates that net cancel
   the per-tensor benefit.

3. **Per-group min-max RTN coupling**: The rotation moves the per-group
   dynamic range of W*s, but min-max RTN bins respond non-linearly to
   the new range. Theta moves that look locally MSE-improving can
   actually shift the bin assignment unfavorably (different group's
   nearest-neighbors). This is the same mechanism that broke
   `(x/s)·(W·s) = x·W` invariance in [[project_paro_k0_falsified_2026_05_22]].

The residual butterfly form (theta=0 reduces to baseline byte-equal)
guarantees the bisectable property holds — but does not guarantee
gradient descent finds anywhere useful. The loss surface around theta=0
has plenty of MSE-decreasing directions that don't correspond to
KLD-decreasing directions.

## What was NOT the failure

- **Theta did move.** Max norm 3.18e-3 means the optimization wasn't
  stuck at theta=0. The optimizer found a non-trivial residual.
- **Identity-residual invariant intact.** theta=0 reproduces baseline
  byte-equal (confirmed by pre-train eval = 0.108986 matches
  uncalibrated MQ4+AWQ exactly).
- **No NaN/inf**, no gradient explosion, no instability. Clean training.
- **No KLD coherence catastrophe.** The +0.31% delta is within noise
  on a 64-seq eval; effectively "no change".

## What this falsifies

- **Residual butterfly via per-Linear BRECQ MSE + SGD on MQ4G256 with
  closed-form AWQ does not reduce model logit KLD on Qwen3.5-0.8B with
  the ButterflyQuant paper hparams.**

What it does NOT falsify (left open for future work):
- Per-tensor SEQUENTIAL optimization (one tensor at a time, paper's
  "layer-by-layer reconstruction"). 138 × 100 steps = 13,800 sequential
  steps. ButterflyQuant paper's exact method.
- Direct KL-divergence loss instead of per-Linear MSE. Much higher
  compute cost (full forward + softmax per step) but aligns the proxy
  with the metric.
- Native ButterflyQuant runtime (replacing FWHT, not residual to it).
  Requires breaking the bisectable property but might unlock the DOF
  the residual form doesn't have access to.
