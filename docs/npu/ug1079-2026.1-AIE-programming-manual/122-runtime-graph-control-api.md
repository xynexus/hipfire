# Runtime Graph Control API

This chapter describes the control APIs used to initialize, run, update, and control the graph execution from an external controller. This chapter also describes how t specify runtime parameters (RTP) in the input graph specification. These parameters affect kernel data processing and change the control flow of the overall graph synchronously or asynchronously.
